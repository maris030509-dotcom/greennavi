# GreenNavi
## サイト概要
### サイトテーマ
  公園の情報を検索・共有や公園での遊び・過ごし方について情報交換できるコミュニティサイト
​
### テーマを選んだ理由
  子どもと公園へ遊びに行く際、新しい公園を探そうとすると、遊具の種類やボール遊びの可否、<br>
  駐車場の有無、公園内の飲食サービスの有無などを調べるために、
  地図アプリや複数のWebサイトを確認する必要があり、手間を感じていました。<br>
  また、公園によっては十分な情報が掲載されておらず、実際に訪れてみると想像していたものと異なり、
  満足に遊べなかったこともありました。<br>
  そこで、公園に関する情報を一箇所に集約したサービスがあれば便利だと考えました。<br>
  さらに、公園での遊び方や過ごし方を利用者同士で共有できる仕組みを提供することで、
  公園をより楽しめる人を増やしたいと考え、このテーマを考えました。
​
### ターゲットユーザ
  ・公園に行くことが好きで新しい公園を探したいと考えている人<br>
  ・公園での過ごし方がワンパターンで新しい楽しみ方を知りたいと思っている人
​
### 主な利用シーン
  ・新しい公園を探そうと思ったとき<br>
  ・公園での過ごし方を探そうと思ったとき
